# CrazyVoice Mobile Companion

**CrazyVoice** is the dedicated Android companion app for **Crazy Audiobook Creator**. Built on the modern Media3 / Compose architecture, it connects your phone directly to your workstation or server over LAN, Tailscale, or domain reverse proxy.

---

## Key Features

1. **Remote Streaming Engine**:
   - **Zero-Latency Playback**: Streams chapters on-demand with HTTP 206 partial-content byte ranges.
   - **Transparent 128k AAC Compression**: Automatically transcodes high-res mastered WAVs into fast-start AAC streams for bandwidth-efficient listening without quality loss.
   - **Live Production Streaming**: Listen to completed chapters while subsequent chapters are still being generated by the GPU pipeline.

2. **Organized Library Navigation**:
   - **Visual Separation**: Distinguishes between `Crazy Audiobooks` (API/Cloud streaming) and `Local Audiobooks` (on-device files).
   - **Live Status Badges**: Shows `⚡ IN PRODUCTION`, `☁️ STREAM`, and `📥 OFFLINE` status indicators.
   - **Full Metadata**: Book titles, authors, narrators, genres, descriptions, and cover artwork.
   - **Unclipped Artwork**: Complete aspect-ratio fitting in the player with smooth rounded corners.

3. **Chapter Navigation & Bookmarks**:
   - **Chapter Marks with Time Offsets**: Interactive bottom sheet displaying all chapter titles with their respective start offsets.
   - **Previous / Next Skipping**: Seamless multi-track navigation.

4. **Two-Way Progress Synchronization**:
   - Automatically persits playback position, chapter number, and playback speed to the server in real-time.
   - Cross-device resume between the web dashboard and mobile phone.

5. **Background Downloader & Offline Support**:
   - Download individual chapters or published delivery batches for offline playback.
   - **Wi-Fi Only Toggle**: User-configurable option in Settings to prevent mobile data usage.

6. **Android Auto & Notification Integration**:
   - Full MediaLibraryService integration for in-car dashboards and lock screen playback controls.
   - Emits rich metadata (`title`, `artist`, `album`, `genre`, `artworkUri`).

---

## Configuration

1. In the app, navigate to **Settings** -> **Crazy Audiobook Creator Server**.
2. Enter your server URL:
   - **Local LAN**: `http://192.168.x.x:8000`
   - **Tailscale**: `http://100.x.x.x:8000`
   - **Domain / Reverse Proxy**: `https://user:password@audiobook.yourdomain.com` (Basic Auth supported)
3. Tap **"Test Connection"** to verify server reachability.
4. Tap **"Sync Audiobooks"** to pull down the latest catalog and chapter manifests.
